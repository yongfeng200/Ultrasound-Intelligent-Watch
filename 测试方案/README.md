## ❓ 常见问题

**Q: 我没有 MATLAB，可以用 Octave 吗？**  
A: 可以尝试，但部分函数可能需要调整。推荐使用 MATLAB R2020b 及以上版本。

**Q: 开发板没有温度传感器怎么办？**  
A: 可以先使用固定温度（如 20°C），后续再添加温度补偿。

**Q: 测试中发现误差很大（> 5%）怎么办？**  
A: 检查：(1) 物理尺寸测量是否准确 (2) TDC tick 周期是否正确 (3) 是否完成零流标定

**Q: 如何判断滤波参数是否合适？**  
A: 运行阶段一测试，对比不同参数下的 MAE、RMSE 和响应延迟，选择最优组合。

**Q: Golden Vector 测试误差多少算合格？**  
A: 误差应 < 0.1%。如果误差 > 1%，说明算法实现有问题。
